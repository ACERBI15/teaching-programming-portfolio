About This Portfolio

I created this website for EDS124BR: Teaching Computational Thinking for Everyone. It documents what I learn throughout the course and shows how my understanding of teaching programming develops over time.

As a Computer Science student, I am familiar with learning technical ideas from a student’s perspective. In this course, I want to look beyond simply making code work. I want to learn how to explain difficult concepts in a simple way, design activities that keep learners involved, and make computing feel approachable for people with different levels of experience.

What You’ll Find Here

SEQUENCING · SNAP!

Drawing a House

In this project, I used a carefully ordered sequence of movement, turning, waiting, and speaking blocks to make a sprite draw a house. In the video, I explain the purpose of the program and how each instruction contributes to the final result.

REPEATS · SNAP!

Breakdancer Program

In this project, I used repeat blocks to create a breakdancer routine. Repeats allow the sprite to move, rotate, and change size multiple times without duplicating the same instructions. The video explains how each repeat works and how changing the number of repetitions would affect the program’s output.
